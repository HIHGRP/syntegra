# State emblems

Each state's coat of arms, named by its ISO 3166-2 code (`NG-AB.png` for Abia State). When the file is present the
platform shows it in the header and on the sign-in page of that state's tenant, and beside the office name when a
user signs in for a government office (for example the Abia State Ministry of Education). Without the file nothing
is shown.

Abia State: "ABSG Coat of Arms Master.png", Government of Abia State, public domain (Wikimedia Commons,
https://commons.wikimedia.org/wiki/File:ABSG_Coat_of_Arms_Master.png). Save it here as `NG-AB.png`.
