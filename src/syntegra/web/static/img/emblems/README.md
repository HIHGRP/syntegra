# State emblems

Each state's coat of arms, named by its ISO 3166-2 code (`NG-AB.png` for Abia State). When the file is present the
platform shows it in the header and on the sign-in page of that state's tenant, and beside the office name when a
user signs in for a government office (for example the Abia State Ministry of Education). Without the file nothing
is shown.

`NG-AB.png` is the coat of arms of Abia State (eagle, leopard and elephant; "God's Own State"; "Prosperity through
Enterprise"), supplied for the platform and reduced to 320 pixels wide for the web. Registration pages (learner
registration, institution registration) carry it with the state's name above the form, and the Abia State Ministry
of Education and the state's education board are marked with it in the regulators' directory and every school's
regulatory profile.
